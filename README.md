# PageCapture

Capture text, links, and images from any browser or chat window on Windows.

## How to use

1. Install using `PageCapture_Setup.exe` from the [Releases](../../releases) section
2. A PageCapture icon appears on your Desktop — double-click it
3. Press **Win+Shift+C** from any browser or chat window OR click the system tray icon
4. PageCapture captures the full content of that window
5. A reader window opens with everything in it
6. Click once to set your **START** point
7. Click again to set your **END** point — everything between highlights
8. Hit **Copy** to clipboard, or **Save** as DOCX, HTML, or TXT

## Features

- Works in Firefox, Chrome, Edge, and most chat apps
- Captures full page content — not just what is visible on screen
- Click-to-click selection — no scrolling needed
- Saves as DOCX, HTML, or TXT
- Copy to clipboard in one click
- System tray — stays out of your way until you need it
- Win+Shift+C hotkey from anywhere

## Download

Go to the [Releases](../../releases) page and download `PageCapture_Setup.exe`

## Notes

- Images from most apps are referenced by name rather than embedded
- Some apps restrict accessibility access — PageCapture falls back to clipboard capture in those cases
- PageCapture never sends any data anywhere — everything stays on your machine
